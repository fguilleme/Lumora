# Optional photographs

Add PNG, JPEG, TIFF, HEIC or DNG files directly to this folder. No photographs are required for synthetic validation. Files are not copied into the app or test bundle. Reports use numbered names rather than exposing original filenames; contact sheets still contain your photographs.

Override the folder with `LUMORA_VISUAL_ASSETS=/absolute/path`. Do not commit personal photographs. Unsupported or unreadable optional files produce warnings.
